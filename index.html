Location Security — Built Right In

Employees can only punch where they work.

Geofencing draws an invisible GPS boundary around each of your locations. Clock in/out only works inside that boundary — whether an employee is on a shared terminal or using a saved shortcut link on their phone.

1. Admin Sets a Boundary

In the Sites settings, toggle Geofence ON, click "Use my current location" while standing at the site, and drag the radius slider. Default is 25m — ideal for a restaurant or retail store. Warehouses and large sites can go up to 500m. One map preview shows exactly what's covered.

2. Every Punch is Verified

When an employee taps IN or OUT, their device's GPS is checked silently in the background. If they're inside the boundary, the punch goes through instantly. If they're outside — whether at home, in a car, or at another location — the punch is blocked with a clear message showing exactly how far away they are.

3. Every Location is Logged

Each punch record stores the GPS coordinates, accuracy, and distance from the site boundary. Admins can review exactly where an employee was when they clocked in — a full location audit trail for every punch.

Strict Mode

If GPS is unavailable or denied by the employee's device, the punch is blocked entirely. Best for sites where location accuracy is critical and you want zero exceptions.

Lenient Mode (Default)

If GPS is unavailable, employees see a warning but the punch still goes through. Ideal for sites with poor indoor GPS signal, or businesses that want a softer rollout.

Optional: Device Token — Double Lock

Enable the Device Token option per site to add a second layer on top of geofencing. Only devices physically registered by a manager via the Kiosk Shortcut panel can punch — even if someone is standing in the right location on an unregistered phone, they're blocked. Geofencing + Device Token together is the strongest protection available.
